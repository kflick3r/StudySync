# StudySync
**AI Study Buddy: An Interactive Study Companion for Students**

StudySync is an AI-assisted study application designed to help students turn their own course materials into personalized and interactive study resources.

Rather than simply providing answers, StudySync is intended to act as a study companion that helps students review concepts, practice what they have learned, and identify gaps in their understanding.

## Project Status

StudySync is currently in the planning and early development stage.

The initial MVP will focus specifically on **Natural Language Processing (NLP)** course material. Limiting the first version to one subject area will allow the application's prompts, generated resources, and AI feedback to be tested and evaluated against familiar course content.

## MVP

Students will provide their own NLP course notes or study material as plain text or Markdown. StudySync will use that material as context for four study modes:

* **Review Guide** — Generate a structured review of key concepts, terminology, explanations, and relationships from the provided material.
* **Flashcards** — Generate flashcards for reviewing important terms and concepts.
* **Multiple Choice** — Practice with generated multiple-choice questions based on the provided material.
* **Short Response** — Answer generated questions and receive feedback, hints, and explanations designed to support understanding rather than immediately reveal the answer.

Students will be able to move between study modes while continuing to use the same course material.

## Technology

The MVP will be built with:

* **Python**
* **Streamlit**
* **HTML/CSS** for optional interface customization
* **One LLM API**
* **Plain text / Markdown** course material

The application will initially run locally in a web browser, with deployment planned after the core MVP is functional and tested.

## Project Goals

Through StudySync, I aim to gain practical experience with:
* Building an interactive AI-powered application
* Integrating an LLM API into a Python application
* Prompt and context design
* Evaluating AI-generated content for accuracy and usefulness
* Designing an application around a real user workflow
* Building and deploying a web application

## Future Development

The NLP-focused MVP is intended as a starting point for the broader StudySync concept.

Future versions may expand to additional subjects and support features such as document uploads, saved study sets, personalized practice, spaced repetition, and long-term progress tracking.
